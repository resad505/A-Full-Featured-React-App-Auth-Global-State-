Assessment Criteria

Navigating with React Router (protected routes redirect non-login) (15 points)
Authentication flow (login form, token storage, logout, session protection on refresh) (20 points)
Global state management (Context + useReducer or Redux Toolkit) (20 points)
Validated forms (React Hook Form or manual validation) (15 points)
CRUD operations against Mock API (json-server etc) with optimistic UI (15 points)
Error boundary — the failure of the tested component to crash the entire application (10 points)
Code structure (feature-based folder organization) (5 points)
